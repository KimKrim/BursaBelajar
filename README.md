# 📈 BursaBelajar — Platform Belajar Investasi & Keuangan

Simulator investasi interaktif berbahasa Indonesia untuk belajar membaca pasar,
mengelola portofolio, dan memahami risiko **tanpa mempertaruhkan uang sungguhan**.

> ⚠️ Aplikasi ini hanya untuk **tujuan edukasi**. Semua harga, berita, dan
> rekomendasi bersifat simulasi dan bukan nasihat keuangan.

## ✨ Fitur Utama

| Fitur | Deskripsi |
|---|---|
| 📈 **Pasar Global** | Saham, reksa dana, obligasi, emas, dan kripto dari berbagai bursa dunia, dengan pita harga berjalan |
| 🗺️ **Heatmap Sektor** | Performa sektor bursa global dalam satu tampilan |
| 🔍 **Analisis & Order** | Order book 5-level (bid/ask), alarm harga, trailing stop, dan form order transaksi |
| 🤖 **AI Advisor & Screener** | Screener multi-indikator (momentum, mean-reversion, risk/reward) dan tanya-jawab per emiten |
| 💥 **Stress Testing** | Simulasi guncangan makro global terhadap portofoliomu |
| 💰 **Passive Income & Dividen** | Proyeksi pendapatan pasif dari dividen |
| 🎯 **Target Impian** | Pelacak tujuan finansial |
| 🔄 **Pembelian Rutin (DCA)** | Jadwal pembelian berkala otomatis |
| 💼 **Portofolio** | Aset, riwayat transaksi, dan ringkasan kinerja |
| 🏦 **Kredit Bank** | Pinjaman, skor kredit, dan pengajuan kredit baru |
| 📰 **Warta Makro** | Berita dan kejadian pasar yang memengaruhi harga |
| 🧮 **Kalkulator** | Compounding interest (DCA) dan konverter valuta asing |
| 👤 **Evaluasi & Backup** | Evaluasi kinerja manajer investasi, ekspor/impor data JSON, reset simulator |

Tambahan: kecepatan waktu simulasi, tema gelap/terang, lencana pencapaian,
dan **Leaderboard** langsung.

## ☁️ Akun & Cloud Save

Progres disimpan ke cloud melalui [Supabase](https://supabase.com), sehingga
riwayat investasi tetap ada saat kamu masuk kembali dari perangkat lain.

## 🚀 Cara Menjalankan

Tidak perlu instalasi atau build.

1. Unduh atau clone repo ini.
2. Buka `Bursabelajar_SE.html` di browser modern.

```bash
git clone https://github.com/<username>/<nama-repo>.git
cd <nama-repo>
# lalu buka Bursabelajar_SE.html di browser
```

Untuk hosting gratis, aktifkan **GitHub Pages** (Settings → Pages → pilih branch `main`).

## 🛠️ Teknologi

- HTML, CSS, dan JavaScript murni (satu file)
- [Supabase JS v2](https://github.com/supabase/supabase-js) untuk autentikasi, cloud save, dan leaderboard
- Font: Bricolage Grotesque & IBM Plex Mono

## ⚠️ Disclaimer

Proyek ini adalah alat belajar. Data pasar adalah simulasi, dan hasil di
dalamnya tidak menjamin hasil di pasar nyata.
